# 💻 AI Product Recommendation System

An AI-powered product recommendation web app built using **React + Vite** with **OpenRouter API integration**. Users can enter product preferences like *“I want a phone under $500”* and receive smart product recommendations instantly.

---

## 🚀 Features
- 🤖 AI-based product recommendations  
- ⚛️ React frontend with clean UI  
- 🔍 Smart product filtering from user input  
- 🛡️ Local fallback recommendation system  
- 🔐 Secure API key handling using `.env`  
- 📱 Responsive and user-friendly design  

---

## 🛠️ Tech Stack
- React.js  
- Vite  
- JavaScript  
- OpenRouter API (DeepSeek Model)  
- CSS

## ⚙️ Installation

```bash
git clone https://github.com/Lalitha-Kandukuri/Product-Recommendation-System-using-API.git

cd Product-Recommendation-System-using-API

npm install

npm run dev
```

---

## 🔑 Environment Variable

Create a `.env` file and add:

```env
VITE_OPENROUTER_API_KEY=your_api_key_here
```
